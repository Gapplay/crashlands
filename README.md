# Crashlands Database

Welcome to the **Crashlands Item Search** project! This web application allows users to search for in-game items and find out where to craft them. The project is built using **JavaScript** and **jQuery**.

## Features

- **Item Search**: Search for various items available in Crashlands.
- **Crafting Locations**: Find out the crafting schematics and ingredientes. 

## Web

You can try the live demo of the project [here](https://gapplay.github.io/crashlands/).
